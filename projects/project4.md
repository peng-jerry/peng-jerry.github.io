Filaments are a cool invention with 3-D Printing but we can achieve more unique properties with Core-Shell-Shell Filaments, where there are 3 filaments wrapped around each other. 

An example of an application are Filament-shaped Dielectric elastomers. These utilize a conductive ionic core and outer layer to allow the filament to bend or elongate when an electrical current is run through. 

My goal was to design a 3-D Printer to manufacture materials such as dielectric elastomers.
