Trivia Game Show

15-113

HW 3

Skills: Python, CustomTkinter, REST APIs, Multithreading

A desktop trivia game in the style of Who Wants to Be a Millionaire, built with Python and the Open Trivia Database API. Questions get progressively harder as you advance: the first third of a game is easy, the middle third is medium, and the last third is hard, with a growing prize ladder to match.

View Source on GitHub

A desktop app, not a web page — clone it and run python main.py to play

Rising Difficulty & the Prize Ladder

Each question is worth more than the last, roughly ×1.6 per step, the same shape as the real show’s ladder. Reaching the end of the easy tier and the end of the medium tier “banks” a safe haven: if a later question is missed, the game ends with the last banked prize instead of nothing, just like the show’s guaranteed checkpoints. A 50:50 lifeline is available once per game to remove two of the three wrong answers.

Calling the Open Trivia Database

Questions come from the Open Trivia Database, a free, keyless REST API — no account or credentials needed. The app fetches multiple-choice questions one difficulty tier at a time via the requests library, along with a session token so the API avoids repeating a question already seen that game. Fetching runs on a background thread so the interface stays responsive while it waits on the network.

Building this also meant working around two real API quirks caught while testing against the live service rather than just its docs: OpenTDB now rate-limits with a plain HTTP 429 in addition to its documented JSON response_code, and its encoding parameter no longer changes the response format, so the app decodes the default HTML-entity-escaped text with Python’s html.unescape instead.

Interface

The UI is built with CustomTkinter on top of Python’s standard Tkinter, in a dark-blue, gold-accented game-show palette. A high score is kept locally between runs.

Future Work

Possible additions include a full visual prize-ladder sidebar, an Ask-the-Audience lifeline, and a difficulty-select override for players who want to skip straight to the hard tier.
